# ME-T1
# 🌿 NaturaTech — Naturaleza e Inteligencia Tecnológica

NaturaTech es un proyecto que une la belleza del mundo natural con el poder de la tecnología moderna.
Exploramos cómo herramientas digitales pueden ayudarnos a monitorear, proteger y comprender mejor
nuestros ecosistemas, desde la biodiversidad hasta el cambio climático.

---

## 🚀 Pasos de instalación y ejecución

1. Clona este repositorio en tu computadora.
2. Asegúrate de tener Python 3.10 o superior instalado.
3. Instala las dependencias del proyecto con el comando `pip install -r requirements.txt`.
4. Configura las variables de entorno en el archivo `.env` (puedes usar `.env.example` como guía).
5. Ejecuta el programa principal con `python main.py`.
6. Abre tu navegador y ve a `http://localhost:8000` para ver la aplicación en acción.

---

## ✨ Características del proyecto

- 🌍 Visualización interactiva de ecosistemas y zonas naturales en tiempo real.
- 📊 Análisis de datos climáticos con gráficas y estadísticas automáticas.
- 🤖 Uso de inteligencia artificial para identificar especies de plantas y animales.
- 🛰️ Integración con imágenes satelitales para monitoreo de deforestación.
- 📱 Interfaz responsiva, accesible desde móviles y computadoras.
- 🔔 Sistema de alertas tempranas ante cambios ambientales detectados.
